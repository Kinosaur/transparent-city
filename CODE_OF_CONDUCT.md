# Code of Conduct

Transparent City is a community project about public information, not a venue for harassment or personal accusations.

We welcome residents, researchers, civic technologists, journalists, public servants, and learners. Participate with respect. Critique ideas, interfaces, methods, and evidence—not people.

Do not publish personal information, dox anyone, make unsupported allegations, or use this project to target an individual or organisation. When you make a claim, distinguish the source data from your interpretation of it.

If you experience or witness behaviour that conflicts with this standard, open a private GitHub report to the repository maintainer rather than escalating the conflict in public.
